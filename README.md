# Bishnu Kumar | Portfolio

A Streamlit portfolio featuring Bishnu Kumar’s data science projects, research, education, and contact information.

## Run locally

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Deploy

Deploy this repository to Streamlit Community Cloud using the `main` branch and `app.py` as the entry point. The app requires no secrets.
